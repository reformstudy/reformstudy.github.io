# Strong's Lexicons

`greek/greek.json` and `hebrew/hebrew.json` are generated by `npm run ingest:strongs` from STEPBible's lexicons (Tyndale House, Cambridge). See each folder's README for the source. License: CC BY 4.0; credit "STEP Bible", linked to www.STEPBible.org.

## Format

```json
{
  "concordance": { "id": "greek", "name": "Strong's Greek Lexicon (STEPBible TBESG)", "language": "Greek",
                   "totalEntries": 5523, "source": { "name": "STEPBible.org, Tyndale House, Cambridge", "url": "…" }, "license": "…" },
  "entries": [
    { "number": "G26", "lemma": "ἀγάπη", "transliteration": "agapē", "partOfSpeech": "Noun, feminine",
      "gloss": "love", "definition": "ἀγάπη, -ης, ἡ\n[in LXX for אַהֲבָה …]\nlove, goodwill, esteem. …" }
  ]
}
```

- `definition` keeps the lexicon's line breaks.
- Only Strong's own numbers are included (G1–G5624, H1–H8674). STEPBible's extended numbers, which tell apart words Strong's grouped together, use the main entry for each number.
- Empty fields are left out.
- There are no verse references yet. Linking words in the text to these entries needs a Strong's-tagged Bible, which is planned for after v1.
