# Strong's Dictionaries

`greek/greek.json` and `hebrew/hebrew.json` are generated by `npm run ingest:strongs`. See each folder's README for source and license (CC-BY-SA: credit required).

## Format

```json
{
  "concordance": { "id": "greek", "name": "Strong's Greek Dictionary", "language": "Greek",
                   "totalEntries": 5523, "version": "1890", "source": { "name": "…", "url": "…" }, "license": "…" },
  "entries": [
    { "number": "G26", "lemma": "ἀγάπη", "transliteration": "agápē",
      "definition": "love, i.e. affection or benevolence; …",
      "kjvDefinition": "(feast of) charity(-ably), dear, love",
      "derivation": "from G25 (ἀγαπάω);" }
  ]
}
```

- Hebrew entries also have `pronunciation`.
- Empty fields are left out.
- The source has no part of speech, usage counts or verse references. Linking words in the text to these entries needs a Strong's-tagged Bible, which is planned for after v1.
