# Strong's Greek Lexicon

`greek.json` is generated by `npm run ingest:strongs` from STEPBible's TBESG lexicon ([STEPBible/STEPBible-Data](https://github.com/STEPBible/STEPBible-Data), pinned to a commit), maintained by Tyndale House, Cambridge. Do not edit it by hand.

Each entry is keyed by its Strong's number and has the Greek word, a transliteration, the part of speech, a one-line gloss, and a definition from Abbott-Smith's *Manual Greek Lexicon of the New Testament*.
