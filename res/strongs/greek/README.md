# Strong's Greek Dictionary

`greek.json` is generated by `npm run ingest:strongs` from [openscriptures/strongs](https://github.com/openscriptures/strongs) (pinned in `scripts/ingest/strongs.js`).

5,523 entries, G1–G5624. Strong never assigned G2717 or G3203–G3302, so those numbers are absent.
