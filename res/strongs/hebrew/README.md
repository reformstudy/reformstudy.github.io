# Strong's Hebrew Lexicon

`hebrew.json` is generated by `npm run ingest:strongs` from STEPBible's TBESH lexicon ([STEPBible/STEPBible-Data](https://github.com/STEPBible/STEPBible-Data), pinned to a commit), maintained by Tyndale House, Cambridge. Do not edit it by hand.

Each entry is keyed by its Strong's number and has the Hebrew word, a transliteration, the part of speech, a one-line gloss, and a definition from a brief edition of Brown-Driver-Briggs.
