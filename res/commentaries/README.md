# Commentaries

## Matthew Henry (`henry/`)

Generated by `npm run ingest:henry`. Don't edit by hand.

- **Source:** [samueldotj/bible-commentaries](https://github.com/samueldotj/bible-commentaries) `en/henry`, pinned to a commit in `scripts/ingest/henry.js`. That repository extracts Henry's *Commentary on the Whole Bible* (1708–1710) from CrossWire's SWORD module `MHC`, which is public domain and prepared from the Christian Classics Ethereal Library text.
- **Coverage:** all 1,189 chapters, 4,253 passage sections, 61 book introductions. Every verse falls in a section.

```
henry/meta.json                  commentary details and the chapters present
henry/{BOOK}/introduction.json   { "book": "ROM", "paragraphs": [ { "text": "…" } ] }
henry/{BOOK}/{chapter}.json      {
                                   "book": "ROM", "chapter": 8,
                                   "introduction": [ { "text": "…" } ],
                                   "sections": [
                                     { "start": 1, "end": 9, "title": "The Believer's Privileges. (a. d. 58.)",
                                       "paragraphs": [ { "text": "…", "refs": [ { "text": "v. 1", "ref": "ROM.8.1" } ] } ] }
                                   ]
                                 }
```

- Henry comments on passages, not single verses. To show the note for a verse, find the section whose `start`–`end` contains it.
- `heading: true` marks a heading paragraph.
- `refs` are the references Henry cites, in his wording and in compact form.
- The source cuts long paragraphs at sentence ends into pieces of about 700 characters; they read as consecutive paragraphs.
- Validation warns about two places where Henry's own sections overlap (Jeremiah 46:12, Jude 15).

The build copies these files one per chapter to `docs/resources/commentaries/henry/`, so the reader downloads only the chapter it shows.
