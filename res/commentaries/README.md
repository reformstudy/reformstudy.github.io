# Commentaries

Two layouts are supported.

## Chaptered (current): `res/commentaries/{id}/`

Used for whole-Bible commentaries. Generated by `scripts/ingest/gill.js` via the **Fetch sources** GitHub Action.

```
gill/meta.json                 commentary details and the chapters present
gill/{BOOK}/introduction.json  { "book": "MAT", "text": "…" }
gill/{BOOK}/{chapter}.json     { "book": "MAT", "chapter": 1, "introduction": "…",
                                 "entries": [ { "verse": 1, "text": "…" } ] }
```

Paragraph breaks in note text are kept as `\n`. The build copies these files as they are to `docs/resources/commentaries/{id}/`, so the reader can download one chapter at a time.

## Single file (legacy): `res/commentaries/{id}/{id}.json`

```json
{
  "commentary": { "id": "matthew-gill", "name": "…", "author": "…", "book": "MAT", "published": 1746, "description": "…" },
  "entries": [ { "book": "MAT", "chapter": 1, "verse": 1, "text": "…", "commentary": "…" } ]
}
```

`matthew-gill` is a placeholder that the reader still uses. Its text is not Gill's own words; it will be removed when the reader switches to the chaptered Gill.
