# Berean Standard Bible

`bsb.json` is generated by the **Fetch sources** GitHub Action, because the source is not reachable from every development environment. To regenerate it locally:

```bash
node scripts/ingest/bsb.js
```

- **Source:** the Free Use Bible API's `BSB/complete.simple.json`.
- **License:** public domain (CC0), dedicated April 30, 2023. See https://berean.bible/licensing.htm.
- **Text:** verse text and Psalm titles (`subtitles`, keyed by chapter). Section headings and footnotes are not kept yet.
- **Versification:** the BSB has 31,086 verses, 16 fewer than the KJV. A few verses are omitted where the BSB follows different Greek manuscripts. `npm run validate:resources` lists each one as a warning.
