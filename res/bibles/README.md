# Bible Versions

One folder per translation: `res/bibles/{id}/{id}.json`. These files are generated by the scripts in `scripts/ingest/`; see each folder's README.

| ID | Translation | Default |
|----|-------------|---------|
| `bsb` | Berean Standard Bible | Yes, when present |
| `kjv` | King James Version | Fallback |

## Format

```json
{
  "version": { "id": "kjv", "name": "King James Version", "abbreviation": "KJV", "language": "en",
               "releaseDate": "1611", "copyright": "Public Domain", "description": "…",
               "source": { "name": "…", "url": "…" } },
  "books": [
    { "id": "GEN", "name": "Genesis", "testament": "OT", "chapters": 50,
      "subtitles": { "3": "A Psalm of David…" },
      "verses": [ { "book": "GEN", "chapter": 1, "verse": 1, "text": "…" } ] }
  ]
}
```

- Book IDs are USFM codes (`GEN`, `SNG`, `NAM`, `1JN`…), listed in `scripts/lib/canon.js`.
- `subtitles` is optional (Psalm titles).
- Files are written one verse per line so a corrected verse is a one-line diff.

## Validation

`npm run validate:resources` (also run by every build) checks all 66 books, chapter counts, verse order and text. The KJV must have exactly 31,102 verses. Other translations are compared with it, and differences are reported as warnings.
